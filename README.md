# Physics Laboratory

A standalone interactive physics learning site built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a modern browser. The site has no build step or package installation.

## Files

- `index.html` — page structure and navigation
- `style.css` — responsive dark interface
- `app.js` — formula library, calculators, graphing, simulations, practice, and unit conversions

## Publish

This repository can be hosted as a static site, for example with GitHub Pages.
